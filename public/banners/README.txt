Drop the left-side banner images here, named by slug:

  army.png
  navy.png
  marine-corps.png
  air-force.png
  space-force.png
  coast-guard.png
  federal-civilian.png

.png, .svg, .jpg, .jpeg and .webp all work. These display 200px wide and stay
frozen in place while the page scrolls, so a tall/portrait image works best
(roughly 200x400 or taller). Any branch without a banner falls back to its
emblem from public/branches, then to a lettered panel.

Files are picked up at build time, so commit and push after adding them.
